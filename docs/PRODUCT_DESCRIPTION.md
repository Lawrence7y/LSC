# LSC 直播切片系统 — 产品说明

**版本**：v3.0.21 ｜ **更新日期**：2026-08-14 ｜ **官网/仓库**：[github.com/Lawrence7y/LSC](https://github.com/Lawrence7y/LSC)

## 一、产品简介

LSC（Live Stream Clipper）是一款面向**电竞直播与多视角内容创作**的**多直播间录制切片系统**。它同时监控多个直播间，同步录制、低延迟预览、精确标记切片，并通过音频互相关对齐实现**多视角画面级同步导出**，支持无畏契约等场景的**持续 AI 高光分析**。

一句话定位：**直播录制 + 快速切片工具**，不是非线性剪辑软件。

| 用户 | 场景 |

## 三、核心功能

### 1. 多房间同步录制（最多 12 路）
- 支持抖音、B站、虎牙、斗鱼、快手、小红书、微博、直链、通用页面等平台
- 独立双进程模式与共享进样模式可选；磁盘满自动保护停录
- 断流自动重连（指数退避），录制文件三层有效性校验

### 2. 低延迟 MSE 预览（最多 4 路）
- 浏览器原生播放（Media Source Extensions），fMP4 流式分片
- 压力升高自动降分辨率/帧率；断流自动恢复与重连

### 3. 精确切片（墙钟级精度）
- 按 `i` / `o` 标记入出点，基于单调时钟 + 墙钟映射导出
- 与预览时间轴解耦，杜绝系统性偏移

### 4. 多视角一键对齐
- 预览流音频互相关对齐（16kHz PCM），自动建立公共时间轴
- 批量导出多视角切片，画面内容同步一致

### 5. 持续 AI 高光分析（无畏契约）
- 纯 OCR 检测：回合交战段自动入列，出点精确到帧
- 主房分析 → 副房时间映射，多视角切片自动对齐入列
- AI 切片默认**待确认**，人工精修后导出，质量可控

### 6. 快速导出与剪映衔接
- 全局导出队列（并发 1~2），支持转码/直拷/竖屏 9:16/缩略图
- 一键生成剪映草稿，无缝进入专业剪辑

### 7. 新手友好
- 首次启动四步引导；全局快捷键；内置检查更新

## 四、技术特性

| 特性 | 说明 |
| :--- | :--- |
| 架构 | Electron + React + TypeScript 前端 ／ Python 后端（编排线程 + WebSocket 桥接） |
| 拉流 | 平台适配器协议化注册，解析缓存与失败熔断 |
| 导出映射 | `export = mark_wallclock − recording_start − content_offset`，亚毫秒级对齐 |
| 隐私 | 纯本地运行、无遥测；URL/Cookie/命令日志自动脱敏（详见 PRIVACY.md） |
| 稳定性 | 长期挂机优化：重连后台化、导出防挂死、内存尖峰控制、日志轮转 |

## 五、安装与使用

### Windows 安装包（推荐）
1. 从 [Releases](https://github.com/Lawrence7y/LSC/releases) 下载 `Setup 3.0.21.exe`
2. 运行安装：安装过程自动下载运行依赖（国内镜像加速），并自动检测/升级 VC++ 运行库
3. 安装完成后直接使用（若机器不支持 DirectML，分析自动降级 CPU，不影响录制）

### 系统要求
- Windows 10/11（64 位）
- 可选：NVIDIA / Intel / AMD 硬件编码；DirectML / CUDA 加速 AI 分析

### 使用流程
```
添加直播间 → 连接 → 开预览/录制 → 按 i/o 标记（或开启 AI 分析）
→ 一键对齐（多视角）→ 确认切片 → 导出（或生成剪映草稿）
```

### 更新
设置页点击「检查更新」，从 GitHub Release 下载新版覆盖安装。

## 六、常见问题（FAQ）

| 问题 | 解答 |
| :--- | :--- |
| 支持哪些平台？ | 抖音、B站、虎牙、斗鱼、快手、小红书、微博、任意直链与通用页面 |
| 能录多少路？ | 最多 12 路并发录制、4 路并发预览 |
| 分析需要显卡吗？ | 推荐；无 GPU 时自动使用 CPU（DirectML 不可用自动降级） |
| 数据存哪里？ | 全部本地：录制文件在您选择的目录，配置在应用数据目录 |
| 会收集我的数据吗？ | 不会。纯本地运行、无遥测，敏感信息自动脱敏 |
