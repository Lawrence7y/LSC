# LSC 直播切片系统 — 认证说明

LSC（Live Stream Clipper）是一个 GitHub 开源项目(https://github.com/Lawrence7y/LSC)，目前已获得 2 星标（当前版本 v3.0.21）。
该应用是一款桌面直播录制与切片系统，主要功能包括：

1. 多直播间同步录制：最多 12 路并发录制，支持抖音、B站、虎牙、斗鱼、快手、小红书、微博及直链/通用页面等平台，断流自动重连
2. 低延迟多路预览：最多 4 路并发预览，支持按 `i` / `o` 键在时间轴上精确标记切片入出点
3. 多视角一键对齐：基于预览流音频互相关对齐，批量导出画面内容同步的多视角切片
4. 持续 AI 高光分析（无畏契约）：自动检测高光回合生成切片列表，人工确认后可一键导出
5. 快速导出与剪映衔接：支持转码/直拷/竖屏 9:16/缩略图，可一键生成剪映草稿继续精剪
6. 简洁用户界面操作：首次启动四步引导、全局快捷键、暗/亮主题切换

测试注意事项：

- 应用无需任何账户即可使用，所有数据均存储在本地（无遥测、无数据上报）
- 网络连接用于：首次启动下载运行依赖（国内镜像加速）、拉取直播流，以及手动检查应用更新（可在设置中查看）
- 应用会在 `%APPDATA%\lsc-electron\` 目录存储配置和日志文件；录制文件默认保存在 `~/LSC/output`（可在设置中修改）
- 如需测试开机启动功能，请在设置中开启相关选项
- AI 高光分析默认使用 DirectML 加速，无 GPU 的机器会自动降级为 CPU 运行，不影响录制功能

*本说明基于产品 v3.0.21 实际功能编写，随版本更新。*
