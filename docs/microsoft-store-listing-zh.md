## 说明 / Description

```
Live Stream Clipper（LSC）是一款多直播间录制与切片工具，专为直播切片师、电竞观众和内容创作者打造。

一次录制 12 路直播
• 支持抖音、B站、虎牙、快手、斗鱼、小红书、微博及直链地址
• 最多 12 路并发录制、4 路低延迟同步预览
• 支持 NVIDIA NVENC / Intel QSV / AMD AMF 硬件编码、CPU 编码，以及原画直拷无损模式

一键切片
• 多房间同步预览，一个屏幕掌控全局
• 按 I / O 键（或点击）在共享时间线上标记入点/出点
• 加入切片列表、确认边界后即可导出——支持竖屏 9:16 或横屏

多视角同步导出
• 一键音频对齐（基于音频互相关算法）
• 同一精彩时刻的多路视角完美同步导出

AI 高光检测（瓦罗兰特）
• 持续分析自动识别对战回合
• 基于 OCR 的回合检测，逐回合复核确认流程
• 停录后自动收尾补扫尾部回合

快速导出工作流
• 全局导出队列，实时进度、一键取消
• 可选一键生成剪映草稿继续精剪
• 导出完成可直接打开文件或所在目录

稳定、私密、本地化：录制、分析与导出全部在本机完成。
```
